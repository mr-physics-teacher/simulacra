Oscilloscope Theory & Operation

An oscilloscope (CRO) displays voltage against time. It allows you to visualize electronic signals, measure their amplitude, and calculate their frequency.

1. Vertical Controls (VOLTS/DIV or Y-Gain)

Scales the Y-axis. If set to 2 V/div, every major grid square vertically represents 2 Volts. Use this to: Make the wave as large as possible on the screen without going off the top or bottom edges (clipping) to minimize percentage uncertainty in your reading.

2. Horizontal Controls (SEC/DIV or Timebase)

Scales the X-axis. If set to 1 ms/div, every major grid square horizontally represents 1 millisecond. Use this to: Stretch or squash the wave horizontally. To measure Time Period accurately, adjust this until you see between 1 and 3 complete waves on the screen.

3. Trigger Level

The oscilloscope draws traces left to right repeatedly. If it draws randomly, the wave looks like a flickering mess. The Trigger tells the scope to wait and start drawing ONLY when the voltage crosses a specific level. Use this to: Stabilize a scrolling or flickering wave.

4. Coupling (AC / DC / GND)

GND: Disconnects the input internally and shows a flat line at 0V. Useful for finding where your 'zero' line is.
DC: Shows exactly what is coming in, including both the Alternating Current (AC) wave and any steady Direct Current (DC) offset pushing it up or down.
AC: Passes the signal through a capacitor, blocking any DC offset. Useful if a tiny ripple is sitting on top of a huge DC voltage and you only want to study the ripple.
